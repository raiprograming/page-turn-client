#tech stack
react
vite 
typescript

#instructions
don't run terminal commands, just give the commands to run it manually.
while writing logical function for components, always add the logical functions in seperate file at the same location. For e.g. all the logical methods of profile component goes in use-login.ts file at the same location. 

#coding standards
use function based components with eslint rules
use mui for design components
use react-router for routing
use mobile first approach for creating ui components
use --primary-color var from index.css file for the main orange color which is theme of the app. 
While writing styles for components, reuse the available styles as much as possible and do not make css files too large.
Always write tsx for the design and not jsx.
